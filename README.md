# 🚍 Public Transport Finder

A simple Streamlit web app to help users find information about various public transport options in the city. Users can select a transport option from a dropdown to view its route, fare, and operating hours.

## 🛠️ Features

- Dropdown menu to select from different buses and routes
- Displays route, fare, and timings for each transport option
- Built using Python and Streamlit

## 📦 Requirements

- Python 3.13 or higher
- Streamlit

You can install Streamlit using pip:

```cmd
pip install streamlit

## How to run project?

- streamlit run main.py
